# Chandan Gupta Portfolio

Static site: open `index.html` in a browser. No build step.
Design follows `reference/behance-reference.png`.

## Admin panel (easiest way to edit)

1. Double-click **`Admin.bat`**. A small window opens and the admin opens in your browser.
   Keep that window open while you edit; close it when you are done.
2. In the admin you can:
   - **Add client**, rename it, set its Instagram handle, category, description and review
   - **Move up / Move down** to change the order of clients on the website
   - **Delete client** (its images go to `images/_trash`, nothing is lost for good)
   - Upload or replace the **logo**
   - Add **posts, stories and carousels** (button or drag and drop), reorder them with the arrows, delete them
   - Pick the panel **colors**, brand palette and tools
   - Edit **Profile and contact**: name, about text, experience, contact links, portrait, polaroids
3. Everything saves automatically. Click **Open website** to check it.

Files are always kept in order (`post-01`, `post-02` ...), so you can still swap an image by hand
by saving a new file under the same name.

To publish, upload the folder to your host. `Admin.bat`, `admin.html`, `css/admin.css`, `js/admin.js`,
`tools/` and `images/_trash` are only needed on your computer.

## Adding lots of images at once (optional)

1. In `images/_drop/` make **one folder per client** and put that client's images inside.
   - Any folder name (e.g. `Cafe Mocha`) becomes the next new project.
   - A folder named `project-02` adds images to project 02.
   - Inside the folder:
     - a file with `logo` in its name becomes the client logo
     - tall 9:16 images, or names containing `story`, become stories
     - everything else becomes a feed post
     - a **sub-folder** becomes one carousel (slides in name order)
2. Double-click `tools/arrange-images.bat`.

Result:

```
images/projects/project-01/logo.png
images/projects/project-01/post-01.jpg, post-02.jpg ...
images/projects/project-01/story-01.jpg ...
images/projects/project-01/carousel-01-01.jpg   (carousel 01, slide 01)
```

- **Replace an image:** save the new file under the same name (e.g. `post-07.jpg`).
- **Reorder:** rename files yourself, then run `tools/arrange-images.bat -ManifestOnly`.
- **After deleting some:** run `tools/arrange-images.bat -Renumber` to close the gaps.
- Sorting is by name (`IMG_2` before `IMG_10`); add `-SortBy Date` to sort by file date.

## Fixed image slots (place these by hand)

| File | Where it shows |
|---|---|
| `images/about/profile.png` | Cut-out portrait with the red outline (transparent background PNG). |
| `images/about/photo-01.jpg` ... `photo-03.jpg` | Polaroid photos. |
| `images/chapter/chapter.png` | Cut-out photo on the "Social media" cover. |

Any missing image shows a dashed placeholder with the file name it expects.
`.jpg`, `.jpeg`, `.png` and `.webp` all work.

## Editing text by hand

Everything written on the site is in `js/content.js` (the admin writes this file for you).
Each client has a `folder` pointing at its images in `images/projects`; the order of clients in the file is the order on the site.

## Files

- `index.html` page structure
- `css/style.css` design
- `js/content.js` your text
- `js/manifest.js` image list, generated by the script
- `js/main.js` builds projects, gallery and lightbox
- `tools/arrange-images.bat` / `.ps1` bulk image renaming
- `Admin.bat`, `admin.html`, `js/admin.js`, `css/admin.css`, `tools/admin-server.ps1` admin panel
